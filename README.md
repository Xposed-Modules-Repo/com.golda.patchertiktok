# TiktokPatchXposed

**Русский** | [English](README-EN.md)

LSPosed-модуль для TikTok: убирает рекламу, открывает функции, которые TikTok включает не всем, и добавляет пару полезных мелочей. Все настройки находятся прямо в TikTok.

Текущая версия — 4.0.1. Проверено на TikTok 47.1.4 из Google Play, Android 16.

## Что умеет

**Лента**
- убирает рекламу: в ленте, на заставке при запуске, внутри видео и в других списках роликов
- скрывает LIVE-трансляции и кнопку LIVE в левом верхнем углу
- скрывает ролики с пометкой «Вы можете знать»
- показывает полосу перемотки на всех видео, включая короткие

**Комментарии и профиль**
- репосты с комментарием
- новый вид профиля с баннерами
- скрытые функции TikTok: ускорение по удержанию, комментарии в избранное, аудио- и фотокомментарии, фоновое воспроизведение и прочее

**Загрузки и ссылки**
- скачивание без водяного знака
- можно скачать любое видео, даже если автор это запретил
- скриншоты и запись экрана работают везде
- чистые ссылки: при копировании из ссылки TikTok убираются параметры отслеживания (`_r`, `_t`, `u_code`, `share_link_id` и т.п.)

**Регион**
- подмена страны SIM-карты, около 190 стран на выбор. По умолчанию стоит Германия, можно выбрать другую страну или выключить. Рекомендации при этом остаются на вашем языке

**Огоньки**
- автоогоньки — по умолчанию выключены, подробнее ниже

Репосты с комментарием, новый профиль и скрытые функции — это серверные эксперименты TikTok, модуль просто включает их у себя. Такие настройки и регион применяются после перезапуска TikTok, на экране настроек для этого появится кнопка.

## Где настройки

TikTok → Профиль → ☰ → Настройки и конфиденциальность → **TiktokPatchXposed** (самая первая строка).

Экран повторяет оформление TikTok и подстраивается под его тему («Показать» → светлая/тёмная) и язык. Переведено на русский, английский, украинский, немецкий, испанский, португальский, французский, итальянский, польский, турецкий и индонезийский. Для белорусского и казахского используется русский, для остальных языков — английский.

Отдельного приложения у модуля нет. Кнопка настроек в LSPosed открывает тот же экран внутри TikTok.

## Установка

1. Установите APK и включите модуль для TikTok в LSPosed.
2. Закройте TikTok (принудительно остановите) и откройте снова.
3. Зайдите в настройки TikTok → TiktokPatchXposed.

При обновлении со старой версии APK ставится поверх. Автоогоньки после обновления нужно включить заново.

## Совместимость

Раньше после каждого обновления TikTok модуль приходилось подгонять под новые имена классов. Теперь он при первом запуске новой версии сам находит нужные места в коде TikTok (по строкам и сигнатурам), на это уходят доли секунды, и запоминает результат. Поэтому новые версии TikTok, скорее всего, будут работать без обновления модуля. Гарантировать это нельзя: если какую-то функцию найти не удалось, модуль её просто пропустит.

Поддерживаются `com.zhiliaoapp.musically` и `com.ss.android.ugc.trill` (второй пакет на устройстве не проверялся).

Модуль работает через современный API LSPosed (libxposed 101–102), поэтому в новых версиях LSPosed нет пометки «legacy». Старые LSPosed 1.9.x тоже поддерживаются: для них в APK оставлен прежний способ загрузки.

## Автоогоньки

Включаются вручную. Модуль продлевает только уже существующие огоньки в личных чатах на двоих и только когда огонёк вот-вот сгорит. Отправка идёт обычным взаимодействием TikTok `spark_v1`, а не текстовым сообщением. Работает, пока TikTok открыт: никаких будильников и фоновых сервисов. Каждая отправка сначала записывается, поэтому один и тот же огонёк не продлевается дважды за день. Между чатами модуль делает паузу в несколько секунд, как если бы вы проходили по ним вручную. Если TikTok не принял огонёк, придёт уведомление: проверьте этот чат сами.

