# TiktokPatchXposed

LSPosed module for TikTok. Source code, full documentation and bug reports: **[github.com/hik0w/TiktokPatchXposed](https://github.com/hik0w/TiktokPatchXposed)**

## English

- removes ads: in the feed, on the startup splash, inside videos and in other video lists
- hides LIVE streams and videos marked "People you may know"; seek bar on every video
- comment reposts, the new profile layout with banners and other hidden TikTok features
- downloads without a watermark, even where the author turned downloads off; screenshots everywhere
- clean links: copied links no longer reveal who shared the video
- region: SIM country spoofing with around 190 countries; recommendations can stay in your language
- invisible mode (test): hide story views, profile visits and video views from people you follow
- auto streaks, off by default

All settings are inside TikTok: Profile → ☰ → Settings and privacy → **TiktokPatchXposed**. The screen follows TikTok's theme and language. Works with LSPosed on the modern API (101–102) and with older LSPosed 1.9.x.

[Full description in English](https://github.com/hik0w/TiktokPatchXposed/blob/main/README-EN.md)

## Русский

- убирает рекламу: в ленте, на заставке при запуске, внутри видео и в других списках роликов
- скрывает LIVE и ролики «Вы можете знать»; полоса перемотки на всех видео
- репосты с комментарием, новый профиль с баннерами и другие скрытые функции TikTok
- скачивание без водяного знака, даже если автор запретил; скриншоты везде
- чистые ссылки: по скопированной ссылке не видно, кто поделился
- регион: подмена страны SIM-карты, около 190 стран; рекомендации можно оставить на своём языке
- невидимка (тестовая): скрыть просмотр историй, профилей и видео у подписок
- автоогоньки, по умолчанию выключены

Все настройки внутри TikTok: Профиль → ☰ → Настройки и конфиденциальность → **TiktokPatchXposed**. Экран подстраивается под тему и язык TikTok. Работает с LSPosed на современном API (101–102) и со старыми LSPosed 1.9.x.

[Полное описание на русском](https://github.com/hik0w/TiktokPatchXposed/blob/main/README.md)
